# 📚 Digital Library Portal

A simple and user-friendly **Digital Library Portal** developed as a frontend web development project. This website allows users to explore books, search for books, and view featured books through a clean and attractive interface.

## 🚀 Features

* 🔍 Search books
* 📖 Featured Books section
* 📚 Book categories
* 🏠 Home page
* 👤 User-friendly interface
* 🎨 Attractive and responsive design
* 🌐 Easy to use navigation

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📂 Project Structure

```text
Digital-Library-Portal/
│
├── index.html
├── style.css
├── script.js
├── images/
│   └── book images
└── README.md
```

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. The Digital Library Portal will open.

## 🎯 Purpose of the Project

The main purpose of this project is to create a simple digital platform where users can browse and search for books easily. It also demonstrates the use of HTML, CSS, and JavaScript in frontend web development.
